## Резюме

Проект имеет сильную основу: Next.js интерфейс, FastAPI text-preview pipeline,
SQL-схему Supabase с RLS, URL/text вход, генерацию постов и промпта, а также
учёт токенов. Однако обязательная цепочка `Image API -> Brandbook Overlay ->
export` не реализована: UI показывает заглушки. Авторизация и сущности проекта
тоже используют mock-данные на frontend. На Live Demo это нужно прямо назвать
demo mode, а не выдавать за production.

Ориентировочный текущий потенциал: **35-45 / 100**. Максимальный балл достижим
только после закрытия P0 ниже.

## Безопасность

- Ключ Gemini, опубликованный в переписке, необходимо отозвать и заменить до
  первого запуска; не добавлять его в Git, README или frontend variables.
- Пароль не хэшируется в браузере: он передаётся только по HTTPS в Supabase
  Auth, который хэширует его серверно. Hash из браузера был бы повторно
  используемым секретом.
- JWT не хранится в localStorage. Сервер выставляет HttpOnly + Secure +
  SameSite cookie, а state-changing endpoints проверяют CSRF token.
